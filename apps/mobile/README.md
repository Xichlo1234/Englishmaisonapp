# ecm_mobile — Ứng dụng Android/iOS

Khung dự án Flutter (bundle id `vn.englishclass.ecm_mobile`). Các màn hình (đăng nhập, lịch học, điểm danh, học sinh, chấm điểm, thông báo) được xây dựng ở Giai đoạn 4.

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

Build iOS cần macOS + Xcode.
